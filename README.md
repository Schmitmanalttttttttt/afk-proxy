# AFK Proxy

Keep Minecraft accounts AFK without running the game. Bots join your server, stay there, and you control them from a control panel in your browser. Java accounts, Bedrock accounts and TheAltening alts.

## Download

New to AFK Proxy: download AFK-Proxy-Setup.zip from the latest release, right-click it, Extract All, then double-click INSTALL. Java is included.

https://github.com/Schmitmanalttttttttt/afk-proxy/releases/latest/download/AFK-Proxy-Setup.zip

Already have AFK Proxy (any version, even the first one): download AFK-Proxy-Update.zip, Extract All, then double-click UPDATE. Your accounts, settings, proxies and logs are kept.

https://github.com/Schmitmanalttttttttt/afk-proxy/releases/latest/download/AFK-Proxy-Update.zip

Windows may say "Windows protected your PC": click More info, then Run anyway.

## Updates

AFK Proxy never updates by itself. When a new version is out, the control panel shows Update available. Click Update, then Yes, update now. Or Remind me in 7 days, or Never. Turn the checks on or off in the control panel under How to, Updates.

This repository only holds the released program (see Releases).
